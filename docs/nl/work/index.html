Hoe een project loopt

  1. Praten

    We zoeken uit wat er echt traag, riskant of kapot is, en wat als eerste de moeite waard is.

  2. Beoordelen

    Ik bekijk de code en servers, en je krijgt schriftelijke bevindingen met duidelijke prioriteiten.

  3. Bouwen

    Nieuw werk of oplossingen, met tests, monitoring en een manier om terug te draaien.

  4. Overdragen

    Documentatie en een rondleiding, zodat je team het zonder mij kan beheren.
