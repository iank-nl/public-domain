01 · The problem

A software company running multiple services on AWS paid for more than it used, without an easy way to see what each part cost.

02 · The approach
  1. Analysed spending per service to see where the money went.
  2. Resized resources that were larger than they needed to be.
  3. Removed resources that were no longer used.
  4. Built automated cost tooling on the AWS SDK, so spending is tracked continuously instead of checked once.
03 · The result
lower AWS costs
~25%

The AWS bill dropped by around 25%, and the automated tooling keeps costs visible so that it does not quietly grow back.
